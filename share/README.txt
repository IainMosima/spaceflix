Spaceflix: watch on any computer, phone or TV on the same Wi-Fi.

1. Install Docker Desktop (once): https://docs.docker.com/get-docker/
2. Start:
     Windows:      double-click "Start Spaceflix.cmd"
     Mac / Linux:  ./spaceflix.sh   (or: make run)
   Each start downloads the newest version first, then opens the app.
3. Stop:  "Stop Spaceflix.cmd"  /  ./spaceflix.sh stop  /  make stop

Movies are saved on this computer:
  Mac ~/Movies/Spaceflix · Linux ~/Videos/Spaceflix
  Windows D:\Movies\Spaceflix (or ~\Videos\Spaceflix with no D: drive)
Change it in the app under Settings. Your phone/TV address is printed on start.
